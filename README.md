# Przeglądarka MRI

Prosty, szybki program do oglądania badań MRI/CT zapisanych w formacie DICOM (np. kopii płyty z pracowni), z wbudowanym serwerem MCP, dzięki któremu Claude może sam przeglądać obrazy i pomagać w ich zrozumieniu.

> **To narzędzie poglądowe, nie diagnostyczne.** Ani program, ani Claude nie zastępują opisu radiologa.

Instrukcja dla użytkownika jest w przygotowaniu.
